QUICK START (3 STEPS):
----------------------

Step 1: Verify Your Setup
--------------------------
python check_model_interface.py

This checks if your model files (model.py, blocks.py, etc.) are compatible.
If it fails, it will tell you exactly what to fix.

Step 2: Test Everything Works
------------------------------
python test_setup.py --zarr-store /path/to/your/data.zarr

Replace with your actual Zarr path. This runs minimal tests to ensure:
- All packages are installed
- GPUs are working
- Data can be loaded
- Model can run

Step 3a: Run Single Experiment (recommended for first test)
------------------------------------------------------------
python fuxi_train.py \
    --zarr-store /path/to/your/data.zarr \
    --train-start 1979-01-01 \
    --train-end 1979-12-31 \
    --val-start 2016-01-01 \
    --val-end 2016-12-31 \
    --max-epochs 5 \
    --exp-name test_run

This runs a quick test with limited data to verify everything works.

Step 3b: Run Full Training Sweep (after testing)
-------------------------------------------------
1. Edit fuxi_sweep.sh:
   - Line 18: Update ZARR_STORE path
   - Line 123: Update conda environment name (if needed)

2. Run the sweep:
   ./fuxi_sweep.sh

This submits multiple SLURM jobs with different model configurations.

Your new setup (FuXi-specific):

KEY DIFFERENCES IN TRAINING APPROACH:
--------------------------------------

1. DATA LOADING:
   Reference: Loads NetCDF into memory
   New: Lazy Zarr loading (zero copy, minimal RAM)

2. PRE-TRAINING:
   Reference: Generic single-step prediction
   New: FuXi paper-faithful (lat-weighted L1, 40k iters)

3. MULTI-GPU:
   Reference: Simple DataParallel
   New: DistributedDataParallel (faster, more efficient)

4. CHECKPOINTING:
   Reference: Saves best only
   New: Saves both best + last (crash recovery)

TROUBLESHOOTING:
----------------

Problem: "Cannot import FuXi from model"
Solution: Run check_model_interface.py - it will guide you

Problem: Out of memory
Solution: Reduce --batch-size or add --use-checkpoint

Problem: Zarr store not found
Solution: Update ZARR_STORE in fuxi_sweep.sh

Problem: NCCL errors (multi-GPU)
Solution: Already handled in sweep script (NCCL_IB_DISABLE=1)
